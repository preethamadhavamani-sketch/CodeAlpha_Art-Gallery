🎨 Aura Frame Studio – Art Gallery Website

A modern, elegant, and responsive virtual art gallery built using HTML5, CSS3, and JavaScript. This project provides an immersive exhibition experience where users can browse curated artwork collections, filter artworks by category, and view each piece in a full-screen interactive lightbox.


✨ Features....

🖼️ Elegant Masonry Gallery Layout – Displays artworks in a visually appealing multi-column grid.

🎨 Category-Based Filtering – Instantly filter artworks into different artistic collections.

🔍 Interactive Lightbox Viewer – View artwork in full-screen with title, description, and navigation controls.

⌨️ Keyboard Navigation – Navigate between artworks using Arrow Keys and close the viewer with Esc.

📱 Fully Responsive Design – Optimized for desktops, tablets, and mobile devices.

🎭 Professional Museum-Inspired UI – Premium typography, artistic frames, smooth hover animations, and minimal aesthetics.

⚡ Smooth User Experience – Fast image loading, subtle transitions, and intuitive navigation.
